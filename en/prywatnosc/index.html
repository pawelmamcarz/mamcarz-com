Privacy

This site sets no cookies, runs no analytics and embeds nothing from third-party domains. What follows describes only the mechanisms that actually run in the site's code.

Who runs this site

mamcarz.com is run by Paweł Mamcarz. For anything concerning data: pawel@mamcarz.com.

What this site does not do

  • It sets no cookies.
  • It uses no analytics tools and no tracking pixels.
  • It embeds nothing from third-party domains. Links to external sites, including YouTube and LinkedIn, are plain links. Nothing loads from them until you click.
  • It loads no fonts from third-party providers. Every typeface is served from this domain.
  • It runs no newsletter and no sign-up forms.

The chat on the contact section

The only component that processes data is the chat. It works as follows:

  • Technical identifier. On first use your browser stores a random identifier in local storage. It contains no name, no email address and no device data: it is a random string generated on your own machine.
  • What it is for. Abuse limiting only, namely a cap of ten messages per minute. The limiter receives only a one-way cryptographic digest of that identifier, never the identifier itself.
  • Message content. What you type is sent to Cloudflare Workers AI, which generates the reply. Do not enter anything you would rather not have processed.
  • Logs. On failure the service records a request identifier, the path and the error class. Message content is not written to logs.

You can remove the chat identifier by clearing site data for mamcarz.com in your browser settings. The chat keeps working: a new random identifier is created on next use.

Hosting

The site runs on Cloudflare Pages and the chat on Cloudflare Workers. As the infrastructure provider, Cloudflare processes technical request data, including IP addresses, to the extent needed to serve the site and protect it from abuse. This happens at platform level, independently of this site's code.

Email contact

If you write to pawel@mamcarz.com, I keep the message and the sender address for as long as the correspondence requires.

Your rights

You may ask what data concerns you, request correction or deletion, or object to processing. Write to pawel@mamcarz.com.
