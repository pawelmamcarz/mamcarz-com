Privacy

Information about data processed by the website, chat and email contact.

Who runs this site

mamcarz.com is run by Paweł Mamcarz. For anything concerning data: pawel@mamcarz.com.

What this site does not do

  • It sets no cookies.
  • It uses no tracking pixels.
  • It embeds nothing from third-party domains. The only resource loaded from outside this domain is the Cloudflare traffic measurement script described below. Links to external sites, including YouTube, LinkedIn and Cal.com, are plain links. Nothing loads from them until you click.
  • It loads no fonts from third-party providers. Every typeface is served from this domain.
  • It runs no newsletter and no sign-up forms.

Traffic measurement

This site uses Cloudflare Web Analytics. Cloudflare adds a script to the pages, loaded from static.cloudflareinsights.com. The script measures page views, visits and page load speed using the browser Performance API, and sends the results to Cloudflare.

According to Cloudflare documentation, the tool uses no cookies or browser local storage and does not identify visitors (so-called fingerprinting) by IP address, User-Agent header or any other data. Cloudflare also states that it does not build visitor profiles from this data for advertising. About the tool: cloudflare.com/web-analytics.

The chat on the contact section

The chat processes the messages you send. It works as follows:

  • Technical identifier. On first use your browser stores a random identifier in local storage. It contains no name, no email address and no device data: it is a random string generated on your own machine.
  • What it is for. Abuse limiting only, namely a cap of ten messages per minute. The limiter receives only a one-way cryptographic digest of that identifier, never the identifier itself.
  • Message content. Messages you send go to a Cloudflare Worker. Some receive a fixed reply straight away and are not sent to any model. The others are first assessed by the Jev model (TypeSafe) running on Cloudflare Workers AI: it receives your latest question and up to four earlier messages from the conversation to recognise the topic, spam or an attempt to bypass the chat rules. Common navigation questions then receive an answer from the site map; the others are sent with the conversation history to a language model on Cloudflare Workers AI. Do not enter anything you would rather not have processed.
  • Logs. On failure the service records a request identifier, the path and the error class. Message content is not written to logs.

You can remove the chat identifier by clearing site data for mamcarz.com in your browser settings. The chat keeps working: a new random identifier is created on next use.

Requests are also limited per network using a hash of the IP address and the day. This hash is sent to the rate limiter; the IP address is not added to chat messages or application error logs.

Hosting

The site runs on Cloudflare Pages and the chat on Cloudflare Workers. As the infrastructure provider, Cloudflare processes technical request data, including IP addresses, to the extent needed to serve the site and protect it from abuse. This happens at platform level, independently of this site's code.

Booking a call

The “Book a call” link on the homepage leads to Cal.com, an external meeting booking service. If you book a call, the data you enter when booking is processed by Cal.com under its own privacy policy, and I receive the details of the booked meeting.

Email contact

If you write to pawel@mamcarz.com, I keep the message and the sender address for as long as the correspondence requires.

Your rights

You may ask what data concerns you, request correction or deletion, or object to processing. Write to pawel@mamcarz.com.
